# Kaah News

Kaah News is a responsive front-end news website built entirely with HTML, Tailwind CSS, and JavaScript. The project is tailored for Somali readers and offers a clean, modern UI reminiscent of major news outlets.

## Technologies Used
- HTML5
- Tailwind CSS (via CDN)
- JavaScript

## Folder Structure
```
/
|-- index.html
|-- about.html
|-- contact.html
|-- js/
|   `-- main.js
|-- assets/
|   `-- images/
|       |-- placeholder1.svg
|       |-- placeholder2.svg
|       `-- placeholder3.svg
```

## How to Run
1. Clone or download this repository.
2. Open `index.html` in your preferred browser. No build steps or server are required.

Optional screenshots can be added to demonstrate the layout of the website.
